# HTML 渲染指南

## 事实源和模板

复制 [`assets/template.html`](../assets/template.html)，只替换模板定义的 `{{...}}` 占位符，不改 CSS、侧栏结构或 JS。单文件必须无外部依赖；使用系统字体、内嵌 CSS 和原生 `<details>`，适配桌面和窄屏。

页面至少包含：总览、十步侧栏导航、每步“输入/输出/学习结果”三栏、可折叠题库、分层费曼讲解和收尾闭环。第 1 步用五视角卡片，第 2 步用冲突/共识关系图，第 6 步用阶梯；其余步骤保持语义清晰，不为了装饰重复内容。

## 占位符清单

| 占位符 | 内容 |
|---|---|
| `{{TOPIC}}` | 主题（HTML 转义） |
| `{{METHOD_INTRO}}` | 方法和学习画像的总览段 |
| `{{STEP_MAP}}` | 10 个步骤导航卡 |
| `{{STEP_N_TITLE}}` / `{{STEP_N_PURPOSE}}` | 第 N 步标题与用途 |
| `{{STEP_N_INPUT}}` | 已填原文提示词与消费上游标签 |
| `{{STEP_N_OUTPUT}}` | 完整原始产物片段 |
| `{{STEP_N_TAKEAWAYS}}` | 3–5 条给人的提炼结论 |
| `{{STEP_N_VIZ}}` | 第 1/2/6 步的语义可视化，其余留空 |
| `{{CLOSING_INTRO}}` | 从开局到压缩的闭环回顾 |
| `{{CLOSING_DELIVERABLES}}` | 事实源、题库、讲解、速查表和练习入口 |
| `{{LOOP_DIAGRAM}}` | 收尾闭环图 |

生成后检查 `{{` 不再出现。第 8/9 步保留状态行“交互施考未进行，对我说‘考我’即可开始”，不能把参考答案或讲解材料误标为用户表现。用户练习后重渲染时，状态行可变为已完成题数/费曼结束状态，但仍以 Markdown 记录为依据。
