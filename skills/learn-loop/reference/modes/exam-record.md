# 模式 B 执行契约：真实施考记录

## 目的

一次只进行一个真实题目事务，以完成的基础题数作为唯一游标，并保留用户逐字回答。

## 允许消费

`run-state.md`、`08-exam-bank.md`，以及已存在的 `08-exam-record.md`。

## 必须产出

首次触发才创建 `08-exam-record.md`；包含会话状态、待回答块、完成的基础题/追问/挑战记录和最终总结。

## 结构约束

- 会话状态字段：当前游标、待回答项、结束状态。
- 当前游标为完成的基础题数 0–10；追问和挑战不增加它。
- 待回答块先保存所属题号、类型、实际提问；用户未答不创建完成事务。
- 完成事务字段：难度、实际提问、用户回答逐字引用、得分、答对处、确切差距、简语重讲。
- 完成记录只追加；待回答块允许原子更新。

## 内容评审

逐字引用、评分和反馈必须基于真实回答；执行模型不能代答或自证原话。

## 允许为空的条件

新会话可没有完成记录，但必须有当前待回答项。最终总结只在十道基础题完成后出现。

## 完成条件

十道基础题事务完整、游标为 10、最终总结一致；挑战可继续单列进行。
