# 模式 C 执行契约：真实费曼复述记录

## 目的

围绕一个真实概念执行教、复述、定位缺口、只重教缺口和再复述的循环。

## 允许消费

`run-state.md`、`03-brief.md`、`09-feynman-notes.md`，以及可选的`08-exam-record.md`。有真实考试记录时优先弱项，未施考时使用简报核心概念。

## 必须产出

首次触发才创建 `09-feynman-record.md`；包含会话状态、待回答块、完成轮次和结束依据。

## 结构约束

- 会话状态字段：当前概念、已完成轮次、待回答项、结束状态。
- 发出教学和复述邀请前先写待回答块；未收到用户复述不增加轮次。
- 每轮字段：本轮教学、复述邀请、用户逐字复述、含糊或跳步处、只重教缺口、下一步。
- 结束状态为进行中、已讲清、仍未通过之一。
- 已讲清必须引用最后一轮用户逐字复述；讲清前不得切换概念。

## 内容评审

缺口判断必须从用户真实措辞出发，备教检查点不是封闭答案表。

## 允许为空的条件

用户停止可结束为仍未通过；不得用模型复述补齐空轮次。

## 完成条件

轮次计数与完成记录一致，状态有真实依据，且没有代写用户复述。
