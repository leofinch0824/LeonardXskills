# 第 8–9 步纪律：备考材料、施考与费曼

## 模式 A 的材料化边界

第 8 步只生成题库，第 9 步只生成讲解材料。流水线不得写 `用户回答`、`逐字引用`、`逐字复述`、答题分数或复述轮次；不要用模型代答来伪造测试效度。

## 题库规格

`08-exam-bank.md` 必须有 10 题：1–3 初级、4–6 中级、7–8 高级、9–10 专家级。每题包含题目、参考答案和 0–10 评分标准，评分标准要分别描述满分、及格、常见薄弱点。最后只给 5 道终极挑战题，并说明全部答好代表的水平，不附答案。

## 模式 B 施考协议

1. 读取题库和 `run-state.md`，从 `08-exam-record.md` 的游标开始，一次只发一道题。
2. 等用户真实回答；未回答时保持游标不变，不补写空答案。
3. 反馈必须包含 0–10 分、答对处、确切差距和简语重讲；弱答可先追问，强答才提高难度。
4. 每题立即落盘，记录用户回答的逐字原话、题号、难度、评分、差距和当前游标。续考只信这份记录。

`当前游标` 是续考唯一权威字段；`已完成题数` 若存在只能作为派生展示值，且必须与 `当前游标` 一致。
5. 十题完成后写最终得分、强弱领域、复习计划和挑战题；低于 6 分的主题交给模式 C。

## 模式 C 费曼协议

以模式 B 的弱项为输入；尚未施考时使用第 3 步核心概念。循环固定为“教 → 用户复述 → 定位缺口 → 只重教缺口 → 再复述”。每一轮记录逐字复述、含糊/跳步位置、重教内容和下一步；结束状态只能是 `已讲清` 或 `仍未通过`。用户未讲清前不得转移到新概念。
