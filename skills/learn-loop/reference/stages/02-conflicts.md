# 第 2 步执行契约：矛盾图谱

## 目的

区分真实冲突、措辞差异和证据未决，比较证据强弱，并界定共识与候选盲区。

## 允许消费

`run-state.md`、`01-perspectives.md`、`perspectives/practitioner.md`、`perspectives/scholar.md`、`perspectives/skeptic.md`、`perspectives/economist.md`、`perspectives/historian.md`。

## 必须产出

`02-conflicts.md`，包含分歧记录、证据强弱比较、关键裁决问题、全体一致、局部一致、盲区判定和本步提炼。

## 结构约束

- 分歧字段：涉及视角、立场 A、立场 B、依据引用、分类、分类理由、需要的验证。
- 分类为实质分歧、措辞分歧、未决之一。
- 证据强弱比较八字段按范本填写；未锚定模式明确比较限制。
- 有实质/未决分歧时恰好一个六字段裁决问题；否则写精确空声明。
- 一致结论八字段按范本填写；全体一致恰好五个支持视角，局部一致为 2–4 个。
- 分级为独立共识或模型先验·待验证之一；同一结论不得重复归类。
- 盲区只保留一个最高影响候选或精确空声明，判定为领域盲区或未覆盖之一。

## 内容评审

检查分歧是否实质、来源是否独立、裁决问题是否可判定，以及盲区措辞是否越界。

## 允许为空的条件

分歧、裁决问题、两组一致和盲区候选都允许按范本写带理由的精确空声明，不得裸写“无”。

## 完成条件

所有引用可解析、互斥值按记录选择、未锚定分支不冒充独立证据，并保留三条本步提炼。
