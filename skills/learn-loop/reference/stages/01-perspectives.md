# 第 1 步执行契约：五视角独立取证

## 目的

让五个隔离角色从不同渠道形成完整、可追溯的正式取证文件，再由父 agent 无损汇总核心产物。

## 允许消费

角色 agent 只消费`run-state.md`与自己的自包含任务包；父 agent 在角色屏障后额外消费五份`perspectives/*.md`正式角色文件。

## 必须产出

五份 `perspectives/*.md` 角色文件与 `01-perspectives.md` 父级汇总。

## 结构约束

- 角色固定为实践者、学者、怀疑者、经济学家、历史学家。
- 每份角色文件包含：两个核心立场句、最强证据、独家洞见、自由视角分析、至少一条检索记录、1–3 个未决问题或带理由的无。
- 最强证据字段：证据主张、来源 URL、来源等级、支持说明；C 级增加未锚定原因。A/B 的来源 URL 只写一个裸 `http(s)` URL，不混入说明或第二个 URL。
- 检索记录字段：查询词、检索渠道、结果状态、来源 URL、取舍理由；状态为采信、未采信、未命中、检索不可用之一。每条记录只保存一个裸 URL，额外来源拆成新的检索记录。
- 父级汇总按固定角色顺序抽取核心立场、最强证据、独家洞见和未决问题，并引用角色文件。
- anchored 模式要求`context/source-audit.md`存在且未决发现为零；A 级重合不足或链接失效按`建议降级`/`链接失效`修正后重跑审计。

## 内容评审

检查角色差异、渠道分化、来源支持关系和完整分析是否保留；不要求模型披露隐藏思维过程。

## 允许为空的条件

未决问题可写`无：理由`；失败检索不得删除。其他要求不得为空。

## 完成条件

五份角色文件分别通过校验，来源审计未决发现为零（anchored），父级汇总与源文件核心值一致，并保留 2–4 条本步提炼。
