# 第 5 步执行契约：资源筛选

## 目的

为当前画像筛出五个真正会使用的资源，识别有依据的坑，并排成一周可完成路径。

## 允许消费

`run-state.md`、`03-brief.md`、`04-review.md`。

## 必须产出

`05-resources.md`：五张资源卡、0–3 个坑点、5–7 个一周行动节点和本步提炼。

## 结构约束

- 资源字段：资源名称、资源类型、来源 URL、来源等级、为什么比同类强、画像适配理由、使用方法、预计耗时、关键收获。
- A/B 必须有 URL；C 的 URL 为无，比较理由声明模型先验和缺失锚定。
- 资源来源等级支持的主张是“资源存在且简介与描述相符”，不是“其内容已被通读”；视频、课程、书籍等非文本媒体资源的 URL 指向资源介绍页或书目页，定级依据为介绍页正文对资源描述的支持程度。
- 非文本媒体资源的`使用方法`必须写清介质形态（读/看/练），已知付费的须注明。
- 坑点字段：对象或做法、风险原因、适用边界、依据引用、替代做法。
- 路径节点字段：时间、资源引用、具体动作、完成证据；时间落在第 1–7 天，资源 1–5 各引用至少一次。

## 内容评审

检查资源比较是否有依据、画像适配是否来自真实输入、总耗时是否可行，以及坑点是否被过度泛化。

## 允许为空的条件

坑点可写`无：未发现有足够依据的被高估项或应避开的坑`；资源和路径不得为空。

## 完成条件

恰好五项资源、路径覆盖完整且完成证据可观察，并保留 2–4 条本步提炼。
