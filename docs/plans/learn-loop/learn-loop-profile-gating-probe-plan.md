## 1. 背景与裁决

VLM 运行暴露画像环节两层缺陷：程序层（三态枚举无中间态、「已给出」无证据标准）与认识论层（零领域认知的裁判解读开场陈述，把主题事实与用户事实混淆——实证：拿「分辨率越高越清楚」这个跨水平普遍的误解定了级；把压着三个子问题（计费规则/任务分档/失效类型）的需求陈述判为明确）。

经双向钢人论证＋单问裁决，定位为「**调研为提问服务**」：

> **调研赚取提问资格，用户的回答赚取锁定权。**

## 2. 设计原则（三条，v2 修订第 3 条）

1. **诊断探针先于画像锁定**：阶段 0 内、画像终填前，跑 2–4 次检索的轻量探针，必检「领域决策空间」与「误解分布」两方向，产出校准过的确认问题清单。
2. **第四态 `推断待确认：`**：单点信念/间接信号不构成「用户开场已提供」，须标`推断待确认：`并经一次性批量确认改记`用户回答：`（可附原推断留痕）。该状态可写入草稿、**不可通过校验**。
3. **（v2 升级）锁定权规则按字段分级，误标通路从构造上删除**：
   - `当前水平`、`角色 / 使用场景`（两个曾经实际失效的字段）：**合法终态前缀唯一＝`用户回答：`**，机器强制。`用户开场已提供`、`推断待确认`、`未提供`均不得作为终态——执行者无法再靠误标绕过，分类判断（「单点信念算不算已提供」）这个不可机检的环节被取消而不是被检验。
   - `目标深度`（实际运行中表现良好）：保留四态（`用户回答：`/`用户开场已提供：`/`推断待确认：`/`未提供`），证据标准＝带范围的目标。
   - 诚实成本：即使开场三项齐全（如「3 年后端／Transformer 学过／两周目标」），`当前水平`与`角色`仍需一轮 recap 式确认（「确认：水平＝…，角色＝…，对吗？」）——这正是施加给「减摩擦人格」的摩擦，与裁决原则的严格版一致。
   - 硬门禁的真实语义：保证**已标注的推断必须经确认改记**、**两高危字段必须以用户回答收尾**；不承诺「问必然发生」（伪造`用户回答：`仍属信任型事项，由留痕＋交付复核兜底）。
